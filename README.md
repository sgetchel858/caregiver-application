# Casanté Family Health Agent: clickable demo

A static demo for iPhone and iPad that runs entirely on mock data, with no server and no real patient data.

- **Live demo:** https://sgetchel858.github.io/caregiver-application/
- **The app, how to run it and how to present it:** [app/README.md](app/README.md)
- **Data contracts** (Health API + Supabase layout): [app/DATA.md](app/DATA.md)

Every push to `main` deploys to GitHub Pages via `.github/workflows/deploy-demo.yml`.
